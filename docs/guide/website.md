# Zag's website

Choose **Download for Mac** to download Zag. Check the macOS and processor requirements beside the download. The download size describes the compressed disk image; the executable size describes the program inside the app. One KiB is 1,024 bytes.

Choose a theme beside the app screenshot to preview its colors. This changes the screenshot, not your installed app. Choose **System**, **Light** or **Dark** in the header to change the website's appearance instead. Use the pause control to stop its animated backgrounds.

In the writing preview, choose **Source** or **Preview**, or drag the divider to compare the Markdown and its rendered page. Open either focus screenshot to see the full window. Press Escape to close it.

Follow **User guide** for editing commands, shortcuts and settings. Follow **Source** to read Zag's code.
